# 萌音整蛊（安卓）

语音包 + 文字转语音 + 录音变声，通过悬浮窗把语音“录”进微信，发成真正的语音条。

## 功能

- **语音包**：首次打开会用文字转语音自动生成 5 条整蛊台词；也可以导入手机里的任意音频（mp3、m4a、wav 等）。点一下试听，长按重命名或删除。
- **文字转语音**：输入文字，用手机自带的语音引擎合成，可以试听、保存到语音包。
- **录音变声**：录一段自己的声音保存到语音包。
- **9 种声音效果**：原声、萝莉、少女、正太、大叔、老爷爷、怪兽、花栗鼠、慢动作。效果在播放时生效，对所有语音都有用。
- **悬浮窗**：在微信上层显示悬浮球，可拖动。面板里可以切换声音、调倒计时（0～3 秒）、开关音量加强。

## 怎么发成微信语音条

1. App 里点「开启悬浮窗」，允许“显示在其他应用的上层”
2. 打开微信聊天，切换到「按住说话」
3. 点悬浮球，选一条语音，悬浮球开始倒计时（默认 2 秒）
4. 倒计时期间按住微信的说话按钮，手机外放的声音会被录进去
5. 悬浮球震动、变绿显示「松手」后，松开手指发送

再点一下悬浮球可以取消。环境安静、不戴耳机效果最好。

## 生成安装包（APK）

项目没有任何第三方依赖，选一种方式即可。

### 方式一：GitHub 自动打包（不用装任何软件）

1. 在 GitHub 新建一个仓库，把这个文件夹里的所有文件上传进去（包括隐藏的 `.github` 文件夹）
2. 打开仓库的 **Actions** 页面，等 “Build APK” 跑完（约 3～5 分钟）
3. 点进这次运行，在底部 **Artifacts** 下载 `MengYin-apk`，解压得到 `app-release.apk`
4. 发到手机上安装（需要允许“安装未知来源应用”）

注意：每次在 GitHub 上重新打包，签名可能不同，覆盖安装失败时先卸载旧版本。

### 方式二：Android Studio

1. 安装 [Android Studio](https://developer.android.com/studio)
2. 用它打开这个文件夹，等待同步完成
3. 手机打开 USB 调试并连上电脑，点运行 ▶；或者菜单 Build → Build APK(s)

## 已知限制

- 微信没有开放直接发语音条的接口，所以只能用“外放 + 麦克风录制”的方式，音质会比原文件略差。
- 部分手机在微信录音时会压低其他声音的音量。如果录进去声音很小，试试开启「音量加强」，或者把倒计时调长一点、让手机离嘴远一点。
- 文字转语音依赖手机系统的中文语音引擎。没有的话在系统设置里搜“文字转语音”安装一个。
- 部分国产系统（小米、华为、OPPO 等）需要额外在设置里给 App 开“后台弹出界面 / 悬浮窗”权限。

## 代码结构

```
app/src/main/java/com/mengyin/prank/
  MainActivity.java     主界面（语音包、文字转语音、录音）
  FloatingService.java  悬浮窗、倒计时、播放与震动提示
  Player.java           播放器，按当前声音效果变调变速
  VoicePreset.java      声音效果列表（想加新效果改这里）
  TtsHelper.java        系统文字转语音
  ClipStore.java        语音包存储
  Prefs.java            设置
  Ui.java               界面样式
```

想换成云端的萌系 AI 配音（阿里云、火山引擎等），只需要替换 `TtsHelper.synth()`，让它调用云端接口把音频保存到同一个文件即可。
